## What to build

GitHub Actions runs the test and build steps on every push and PR, so a broken engine test or a
failing build is caught before it reaches a branch, independent of any deployment.

## Acceptance criteria

- [ ] `.github/workflows/ci.yml` runs `dotnet test api`, `pnpm --dir web lint && pnpm --dir web build`, and `docker build ./api` and `./web` on push and PR.
- [ ] The workflow is green on the `feat/scaffold` branch.
- [ ] Breaking `MoneyTests` locally and pushing makes the workflow fail; reverting makes it pass again.
