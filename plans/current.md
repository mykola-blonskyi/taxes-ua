# Current Plan

## Goal

Этап 1, MVP: учёт поступлений, расчёт ЕП/ВЗ/ЕСВ, сроки, реестр платежей с балансами,
главный экран, цифры для декларации, настройки, экспорт и бэкап, PWA. Backend .NET, frontend Next.js,
деплой в Coolify. Оценки в рабочих днях, грубые.

Согласовано владельцем 2026-09-25.

---

## Phase 1. MVP

- [ ] 1.1 Скелет (1 день). Документы в knowledge/ и plans/. `api/` решение .NET 10: Engine, Api, тесты.
      `web/` Next.js. Dockerfile для обоих, `docker-compose.yml` для Coolify, `.env.example`.
      `/api/health` с проверкой БД. Деплой пустого приложения с Postgres в Coolify.
- [ ] 1.2 Движок (2 дня). Типы, доход по периодам с возвратами, ЕП/ВЗ/ЕСВ по кварталам и месяцам,
      нарастающий итог, сроки с переносом, балансы по видам, переплаты, лимит, авансы.
      Тесты: эталон 2026, регистрация посреди квартала, переход года, возвраты, переплаты,
      валютные поступления, выходные НБУ.
- [ ] 1.3 БД и auth (1 день). EF Core схема, миграции, seed `TaxYearConfig` 2026, Identity с Google
      и allowlist, passkey, `AuditLog`.
- [ ] 1.4 Поступления (1 день). API и экран CRUD, курс НБУ с откатом на рабочий день и кэшем,
      ручная правка курса, типы операций.
- [ ] 1.5 Платежи в бюджет (0.5 дня). CRUD, балансы по видам.
- [ ] 1.6 Главный экран, периоды, цифры для декларации (1.5 дня).
- [ ] 1.7 Настройки (0.5 дня). Профиль ФОП, режим оплаты, параметры по годам, предупреждение
      о непроверенном годе.
- [ ] 1.8 Экспорт и бэкап (1 день). CSV/XLSX, бэкап и восстановление JSON, импорт JSON прототипа.
- [ ] 1.9 Оболочка (1 день). PWA, тёмная тема, адаптив, каркас i18n, дисклеймер.

Каждый шаг заканчивается проверкой на реальном деплое.

## Risks

- Трактовка срока уплаты ЕП/ВЗ при переносе декларации не подтверждена. Сделано настраиваемым.
- ЕСВ в месяц регистрации не подтверждён. Сделано настраиваемым.
- Типы между C# и TS расходятся при ручном дублировании. Типы генерируются из OpenAPI.
- ФОП ещё не зарегистрирован. Дата регистрации в будущем, реальные данные появятся позже,
  движок проверяется на синтетике и эталоне.
- API monobank может не показывать ФОП‑счета. Проверяется токеном владельца на Этапе 2.
